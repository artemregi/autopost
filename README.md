# Урок. Автопостинг в Instagram

Готовый ролик сам выходит в Instagram: с обложкой, описанием и хештегами, по одному раз в час. Каждый день в Telegram приходят итоги: просмотры, досмотры, лайки, сохранения и какой ролик лучше.

Раньше система писала сценарии, аватар снимал, монтаж собирал ролик. Теперь ролик выходит сам. Дальше статистика покажет, какие темы заходят, а следующий урок превращает просмотры в заявки.

Делай шаги строго по порядку. Текст в серых блоках копируй целиком: наведи мышку на блок, справа появится кнопка копирования.

---

## Что нужно заранее

- Установленная система сценариев из урока 1: папка `scenarios` в домашней папке, Telegram-бот присылает сценарии.
- Готовый вертикальный ролик: из урока про монтаж (папка `montage/готовые`) или любой свой mp4.
- Аккаунт Instagram, в который будут выходить ролики, и телефон с приложением Instagram.
- Аккаунт Facebook: через него входят в кабинет разработчика Meta. Связывать Instagram с Facebook не нужно.
- Компьютер включён в то время, когда ролики должны выходить.

Если на каком-то шаге кнопка называется иначе или её нет, сделай скрин и пришли Claude: открой систему (`cd ~/scenarios`, потом `claude --dangerously-skip-permissions`), перетащи картинку в окно и напиши «Я на шаге N урока автопостинга, что нажать?». Скрин на Mac – Cmd + Shift + 4, на Windows – Win + Shift + S.

---

## Шаг 1. Профессиональный аккаунт Instagram · 3 минуты

Официальный API публикует только в профессиональный аккаунт: «Автор» или «Бизнес». Подписчики и старые публикации при переключении остаются.

1. Открой Instagram на телефоне → свой профиль → три полоски справа вверху.
2. **Тип аккаунта и инструменты** → **Переключиться на профессиональный аккаунт**.
3. Выбери категорию, потом **Автор** или **Бизнес**. Для блога эксперта подходит «Автор».

**Проверь:** в профиле под описанием появилась кнопка **Профессиональная панель**.

Если аккаунт уже профессиональный, этот шаг пропусти.

## Шаг 2. Подключить Instagram API · 20–30 минут

Здесь ты создаёшь своё приложение у Meta и получаешь токен – длинный ключ, по которому система публикует ролики в твой аккаунт. Всё делается на компьютере в браузере, один раз. Кабинет Meta бывает на русском или на английском: в скобках английские названия кнопок.

### 2.1. Кабинет разработчика

1. Открой developers.facebook.com.
2. Справа вверху **Начать** (Get Started) или **Войти** (Log In) → войди своим аккаунтом Facebook.
3. Meta попросит подтвердить почту или телефон и выбрать, кто ты. Выбирай **Разработчик** (Developer).

**Проверь:** вверху страницы есть **Мои приложения** (My Apps).

### 2.2. Создать приложение

1. **Мои приложения** (My Apps) → **Создать приложение** (Create App).
2. Название – любое, например «Автопостинг». Почта – твоя. **Далее** (Next).
3. Сценарий использования (Use case): **Управление сообщениями и контентом в Instagram** (Manage messaging & content on Instagram). **Далее**.
4. Бизнес-портфолио: **Я пока не хочу подключать бизнес-портфолио** (I don't want to connect a business portfolio yet). **Далее**.
5. **Создать приложение** (Create app). Meta может попросить пароль от Facebook.

Откроется панель приложения.

### 2.3. Открыть настройку Instagram

1. В панели приложения слева **Сценарии использования** (Use cases).
2. У сценария про Instagram нажми **Настроить** (Customize).
3. Открой **Настройка API с входом через Instagram** (API setup with Instagram login).

Посмотри раздел **Разрешения** (Permissions). Нужны три разрешения:

- `instagram_business_basic`
- `instagram_business_content_publish`
- `instagram_business_manage_insights` – для статистики

Если у какого-то есть кнопка **Добавить** (Add), нажми её.

### 2.4. Добавить свой Instagram тестировщиком

Пока приложение в режиме разработки, оно работает только с аккаунтами, у которых есть роль в приложении. Свой аккаунт нужно добавить.

1. В панели приложения слева **Роли приложения** (App roles) → **Роли** (Roles).
2. **Добавить людей** (Add People) → **Тестировщик Instagram** (Instagram Tester).
3. Впиши ник своего Instagram без @ → **Добавить** (Add).
4. Прими приглашение: открой instagram.com в браузере, войди в этот аккаунт → **Настройки** → **Приложения и сайты** (Apps and websites) → **Приглашения тестировщика** (Tester invites) → **Принять** (Accept).

Если твой аккаунт уже стоит в ролях, этот пункт пропусти.

### 2.5. Сгенерировать токен

1. Вернись в **Сценарии использования** → **Настроить** → **Настройка API с входом через Instagram**.
2. В блоке **Сгенерируйте маркеры доступа** (Generate access tokens) нажми **Добавить аккаунт** (Add account).
3. Войди в свой Instagram и разреши доступ.
4. Аккаунт появится в списке. Нажми рядом **Сгенерировать маркер** (Generate token).
5. Скопируй токен целиком. Это длинная строка из букв и цифр.

Токен – это доступ к публикациям в твой аккаунт. Не пересылай его никому и не выкладывай. Вставишь его только в Claude на шаге 3.

Приложение остаётся в режиме разработки. Отправлять его на проверку Meta (App Review) не нужно: ты публикуешь только в свой аккаунт.

**Готово, когда** токен скопирован. Если Meta пишет ошибку при входе в Instagram, сделай скрин и пришли Claude.

## Шаг 3. Установить модуль · 10 минут

Открой систему как обычно:

1. Терминал (Mac) или PowerShell (Windows).
2. Команды по очереди, после каждой Enter:
   ```
   cd ~/scenarios
   ```
   ```
   claude --dangerously-skip-permissions
   ```

Вставь в Claude текст целиком и нажми Enter:

```
Установи мне модуль автопостинга в Instagram. Делай сам, команды запускай сам, у меня спрашивай только то, что указано.

1. Скачай https://github.com/artemregi/autopost/archive/refs/heads/main.zip, распакуй во временную папку и скопируй в текущую папку scenarios файлы autopost.py, ig_api.py, cover.py, stats.py, а файл knowledge/reel_description.md – в папку knowledge. Остальные мои файлы не трогай. Временную папку и архив удали.
2. Проверь, что есть ffmpeg. Нет – Mac: brew install ffmpeg, Windows: winget install Gyan.FFmpeg.
3. Поставь библиотеку Pillow в окружение системы: Mac – .venv/bin/python -m pip install pillow, Windows – .venv\Scripts\python -m pip install pillow.
4. Спроси у меня токен Instagram из шага 2 и сохрани его: ig_api.py token <токен>. Токен никогда не выводи на экран и никуда не копируй.
5. Проверь токен: ig_api.py me. Должно быть ✅ и мой ник. Если ❌ – объясни мне простыми словами, что поправить в кабинете Meta, дождись, пока я поправлю, и проверь ещё раз.
6. Сухой прогон без публикации: возьми самый свежий ролик из ~/montage/готовые (папки нет или она пустая – спроси у меня путь к любому вертикальному mp4), запусти autopost.py add <ролик> --dry-run, потом autopost.py now --dry-run. Открой обложку из папки dry-run и покажи мне. Ошибки почини. Потом удали папку dry-run.
7. Включи расписание: autopost.py on, потом autopost.py status.
8. Отправь в мой бот сообщение «Модуль автопостинга установлен. Ролики выходят из очереди раз в час».
9. В конце напиши мне: «Готово. Поставь первый ролик в очередь».
```

**Готово, когда** в Telegram пришло «Модуль автопостинга установлен».

## Шаг 4. Первый ролик · 10 минут

Вставь в Claude:

```
Поставь в очередь на Instagram мой последний ролик из ~/montage/готовые. Посмотри несколько кадров и выбери для обложки секунду, где я спокойно смотрю в камеру, – запусти autopost.py add <ролик> --at <секунда>. Покажи мне обложку и описание. Если я скажу поправить – поправь caption.txt или пересобери обложку. Когда я скажу «ок», выложи сразу: autopost.py now.
```

Что произойдёт:

1. Claude расшифрует ролик и напишет описание по правилам из `knowledge/reel_description.md`: призыв с кодовым словом, если оно есть в ролике, фразы, по которым ролик ищут, до 5 хештегов. Тон берётся из твоей анкеты `anketa.md`.
2. Обложка – кадр из ролика с крупным заголовком сверху.
3. В Telegram придут обложка и описание.
4. После «ок» ролик загрузится в Instagram. Через несколько минут бот пришлёт ссылку: «Вышел пробный рилс».

**Проверь:** открой ссылку из Telegram. Ролик открывается, описание и обложка на месте.

В сетке профиля пробного рилса нет – так и задумано. Об этом ниже.

---

## Пробный или обычный рилс

**Пробный** (стоит по умолчанию). Instagram показывает его только тем, кто на тебя не подписан. В сетку профиля и подписчикам он сам не попадает. Неудачный ролик не портит профиль, а удачный можно перевести в обычный руками в приложении Instagram: открой рилс и найди кнопку перевода. Если не нашёл, сделай скрин и пришли Claude.

**Обычный.** Выходит в профиль и подписчикам, как если бы ты выложил его с телефона. Включить: «Впиши в .env AUTOPOST_MODE=normal».

Если Instagram не принимает пробный режим для твоего аккаунта, ролик в профиль сам не выйдет: он уйдёт в папку `failed`, а бот напишет ошибку. Тогда включи обычный режим и запусти `autopost.py retry`.

## Как пользоваться каждый день

1. Монтаж собрал ролик в `montage/готовые`.
2. Открой систему и скажи Claude: «Поставь в очередь ролик <название>». Можно несколько сразу.
3. В Telegram придут обложка и описание каждого ролика. Не нравится – скажи Claude, что поправить, до публикации.
4. Ролики выходят по одному: не чаще раза в час и только с 9:00 до 22:00 по часам компьютера. После каждого бот присылает ссылку.
5. Каждый день в 10:00 бот присылает статистику.

Очередь лежит в папке `scenarios/queue`: на каждый ролик своя папка с `video.mp4`, `cover.jpg` и `caption.txt`. Номер в начале имени – порядок выхода. Вышедшие переезжают в `scenarios/posted`, невышедшие – в `scenarios/failed`.

Компьютер должен быть включён и не спать. Если он спал, очередь продолжится, когда проснётся. После перезагрузки расписание работает само.

### Как читать статистику

- **Просмотры** – сколько раз ролик посмотрели.
- **Досмотр** – какую часть ролика в среднем смотрят: 50% значит, что в среднем смотрят половину.
- **Лайки, сохранения, репосты** – как в приложении.
- Внизу – какой ролик набрал больше всего просмотров и какой лучше досматривают.

Ролик младше 2 суток помечен «ещё набирает»: показы ещё идут, сравнивать его с остальными рано.

### Что важно знать

- **Токен живёт 60 дней.** Система продлевает его сама раз в неделю, когда выкладывает ролик или собирает статистику. Если компьютер был выключен дольше 60 дней, токен перестанет работать: сделай новый (шаг 2.5) и отдай Claude.
- **Видео на время уходит на uguu.se.** Instagram забирает ролик сам по ссылке, поэтому система кладёт файл на сервис временных файлов. Там он лежит по случайной ссылке и удаляется сам через 3 часа.
- **Место на диске.** Вышедшие ролики остаются в `posted`. Видео оттуда можно удалять, для статистики нужен только `meta.json`.

## Если что-то не работает

Открой систему (`cd ~/scenarios`, потом `claude --dangerously-skip-permissions`) и вставь:

```
Почини автопостинг. Запусти ig_api.py me, autopost.py status и autopost.py list, посмотри logs/autopost.log. Если токен не работает – объясни мне простыми словами, как сделать новый (developers.facebook.com → моё приложение → Сценарии использования → Настройка API с входом через Instagram → Сгенерировать маркер), сохрани его через ig_api.py token и проверь ig_api.py me. Если ролики лежат в failed – прочитай ошибку и объясни. Если ролик точно не вышел в Instagram – верни его в очередь: autopost.py retry. Если расписание выключено – autopost.py on.
```

Частые причины:
- **«Нет токена» или «Error validating access token»** – токен истёк или не сохранился. Сделай новый (шаг 2.5).
- **«Insufficient developer role»** при входе в Instagram – аккаунт не добавлен тестировщиком или приглашение не принято (шаг 2.4).
- **Ошибка про пробный режим (trial)** – Instagram не дал пробный рилс этому аккаунту. Включи обычный: «Впиши в .env AUTOPOST_MODE=normal».
- **«Не загрузился на uguu.se»** – нет интернета или сервис временно не отвечает. Система попробует ещё раз через 10 минут.
- **Ролик не выходит** – сейчас вне окна 9:00–22:00, с прошлого ролика не прошёл час или компьютер спал. Посмотреть: «Покажи очередь».
- **Не пришла статистика** – компьютер был выключен в 10:00. Попроси: «Пришли статистику».

## Команды

| Что | Команда в Claude |
|---|---|
| Поставить ролик в очередь | «Поставь в очередь ролик <название или путь>» |
| Со своим описанием | «Поставь в очередь ролик <название> с описанием: <текст>» |
| Со своей обложкой | «Поставь в очередь ролик <название> с обложкой <путь к картинке>» |
| Что в очереди | «Покажи очередь: autopost.py list» |
| Поправить описание | «Поправь описание ролика N в очереди: <что поменять>» |
| Убрать из очереди | «Убери из очереди ролик N: autopost.py remove N» |
| Выложить прямо сейчас | «Выложи следующий из очереди сразу: autopost.py now» |
| Статистика сейчас | «Пришли статистику: stats.py» |
| Реже или чаще | «Впиши в .env AUTOPOST_EVERY_MIN=120» (минуты между роликами) |
| Другое окно публикации | «Впиши в .env AUTOPOST_HOURS=10-21» |
| Обычные рилсы вместо пробных | «Впиши в .env AUTOPOST_MODE=normal» |
| Статистика в другое время | «Включи автопостинг заново: autopost.py on 09:00» |
| Выключить автопостинг | «Выключи автопостинг: autopost.py off» |
| Проверить токен | «Проверь токен Instagram: ig_api.py me» |
| Продлить токен сейчас | «Продли токен Instagram: ig_api.py refresh» |
